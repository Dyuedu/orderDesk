# Contributing to OrderDesk

## Branches

Name the branch for the story and include the ticket id.

```text
FR-204-require-refund-reason
```

Do not push commits to `main`. Open a pull request instead.

## Commits

- One change per commit. The subject must be a single sentence without the word "and".
- Use the imperative mood: `Require refund reason on approve`.
- Keep the subject under about 50 characters.
- Put the *why* in the body. Do not restate the diff.

## Pull requests

The description must include:

1. What the change does.
2. Why it is needed.
3. Numbered verification steps.
4. The one point you are least sure about.

Wait for review before merge. Do not merge your own unreviewed work.

## Review

Comments go on a specific line. Say what would go wrong if that line stayed. Mark blocking comments as **Blocking**. Ask at least one question. Reply to every comment on your own pull request.
